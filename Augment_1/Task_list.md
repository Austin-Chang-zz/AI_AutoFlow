
## 🎯 **Augment Code任務功能完整指南**

### **任務功能的位置和作用**
```
位置：對話頂部的"+"按鈕
作用：創建和管理當前對話的工作任務
特點：幫助組織複雜項目，追蹤進度
```

## 📋 **如何添加和使用任務**

### **添加任務的步驟**
```
1. 點擊對話頂部的"+"按鈕
2. 選擇"Add Task"或"添加任務"
3. 輸入任務名稱和描述
4. 設置任務狀態（可選）
5. 點擊"Save"或"保存"
```

### **任務狀態說明**
```
[ ] NOT_STARTED - 未開始
[/] IN_PROGRESS - 進行中  
[x] COMPLETE - 已完成
[-] CANCELLED - 已取消
```

## 🔧 **修改已完成任務的方法**

### **重新激活已完成的任務**
```

3. 將狀態從 COMPLETE 改為 IN_PROGRESS [/]
4. 修改任務描述（如果需要）

方法2：創建升級版本任務
1. 保留原任務為 [x] 已完成
2. 創建新任務："升級版 - [原任務名稱]"
3. 在新任務中描述升級需求
4. 設置為 [/] 進行中
```

    });

升級版本代碼：
```javascript
// v2.0 添加記住登錄和錯誤處理
function login(username, password, rememberMe = false) {
    return fetch('/api/login', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({username, password, rememberMe})
    })
    .then(response => {
        if (!response.ok) throw new Error('登錄失敗');
        return response.json();
    })
    .catch(error => {
        console.error('登錄錯誤:', error);
        throw error;
    });
}
```

## 🤖 **AI任務關閉確認機制**

### **核心答案：是的，AI會主動詢問確認**
```
✅ AI會在以下情況主動詢問任務關閉確認：
- 用戶報告完成了任務的主要部分
- AI檢測到任務要求基本滿足
- 用戶暗示任務可能已完成
- 長時間沒有該任務的進展更新

❌ AI不會：
- 在沒有用戶輸入的情況下自動關閉任務
- 忽略用戶的反對意見強制關閉
- 在任務明顯未完成時建議關閉
```
